\vspace{1cm}

Preparing for technical software engineering interviews in the modern era presents significant challenges for students and aspiring developers. Traditional study methods are often fragmented across disparate platforms, suffer from outdated static content, lack structured model explanations, and provide zero administrative visibility into candidate learning deficits. 

This project presents \textbf{OmniFAQ AI}, an intelligent, full-stack tech interview preparation web platform that unifies high-quality curated technical interview repositories with real-time generative capabilities powered by \textbf{Google Gemini Generative Artificial Intelligence}. Developed using a three-tier client-server architecture, the system incorporates an ultra-responsive, single-page application (SPA) frontend designed with modern glassmorphism aesthetics, backed by a modular \textbf{PHP 8.2 REST API} router and a high-performance relational database engine.

A pivotal innovation of the platform is its \textbf{dual-driver database persistence architecture}, which dynamically binds to cloud-hosted MySQL/MariaDB instances when reachable, while offering automatic, zero-configuration failover to an embedded SQLite engine equipped with self-seeding mechanisms. Furthermore, the platform introduces an \textbf{automated self-learning loop}: when candidates query emerging or un-indexed technical topics, the backend triggers Google Gemini Generative API under strict JSON schema constraints. The synthesized questions, comprehensive model answers, taxonomic categories, and difficulty tiers are simultaneously delivered to the user and persisted into the database, transforming transient AI inferences into permanent knowledge assets without redundant API overhead.

In addition, the system incorporates a client-side practice evaluation engine measuring conceptual keyword coverage, role-based access control secured by Bcrypt cryptographic hashing, and a comprehensive administrative telemetry dashboard tracking search volume, query resolution percentage, and unresolved student inquiries. The platform has been containerized using \textbf{Docker} and successfully deployed on the \textbf{Render} cloud platform, demonstrating high reliability, sub-second latency, and horizontal scalability.
